Grid Usage:

The grid allows you to specify exact X and Y coordinates for icons and other elements. Each grid line represents 10px, making it easy to position elements precisely. For example:

  • X: 0px = Left edge
  • X: 10px = First vertical line
  • X: 20px = Second vertical line
  • Y: 0px = Top edge
  • Y: 10px = First horizontal line
  • Y: 20px = Second horizontal line

Ready for: Icons and other elements to be placed at exact X,Y coordinates you specify.
