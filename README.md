## 🎯 OVERVIEW

**Frontend Glass Configurator** is a modern, interactive web application that allows customers to configure custom glass products in real-time. The application features: 

- 🎨 **Glassmorphism Design**: Modern frosted glass aesthetic with blur effects
- 🛒 **Interactive Configurator**: Configure glass products step-by-step
- 💰 **Real-time Pricing**: Dynamic price calculation as you configure
- 📱 **Fully Responsive**: Works perfectly on phones, tablets, and desktops
- 🔐 **CRM Integration**: Seamlessly connected to malta-real-estate-crm backend
- 🌍 **Multi-language**:  Supports multiple languages (Extensible)
- ✨ **Modern UI/UX**: Clean, intuitive interface optimized for users aged 28-40

### **Purpose**

The configurator transforms standard glass product sales by allowing customers to:
1.  Visualize their custom glass configuration
2. See real-time pricing updates
3. Save and manage configurations
4. Submit orders directly through the CRM system
